1. Se copiază folder-ul cu conținutul proiectului și se rulează în Visual Studio OrderProcessing.sln pentru adaptarea dependențelor backend-ului;
2. Se rulează în Developer Powershell, în OrderProcessing.UI:
     - npm install pentru instalarea dependențelor frontend și pachetelor;
     - npm run dev pentru rularea componentei UI React;
     - npm run electron într-un Developer Powershell separat pentru rularea proiectului cu ajutorul pachetului Electron (portarea din aplicație WEB în aplicație Desktop)
